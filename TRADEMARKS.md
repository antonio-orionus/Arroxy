# Arroxy name and logo

The code is free software under the GNU GPL v3 or later: you may fork it,
change it, and redistribute it, including for money, as that license allows.
The license covers the code. It grants no rights to the name "Arroxy" or the
Arroxy logo, which identify the builds Antonio Orionus publishes.

## You may

- Say your project is "based on Arroxy" or "a fork of Arroxy".
- Use the name to refer to Arroxy accurately: in articles, reviews, tutorials,
  comparisons, and package listings that install the official builds.
- Package the official, unmodified builds for a distribution or package
  manager under the Arroxy name.

## You may not, without written permission

- Publish a modified build, or a build from a fork, named "Arroxy" or with a
  confusingly similar name or icon.
- Use the name or logo in a way that suggests your build, product, or service
  is official or endorsed.
- Use the name or logo in an app store listing, domain, or account name for
  anything other than the official builds.

A fork needs its own name and icon. Its about screen and listings should make
clear that it is not Arroxy.
