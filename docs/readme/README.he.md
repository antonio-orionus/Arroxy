<summary><strong>🧭 גילוי: גלישה באינטרנט בתוך Arroxy</strong></summary>

- **הכרטיסייה “גילוי”** — גלשו ב-YouTube או בכל אתר אחר בתוך Arroxy והורידו את מה שמצאתם בלי להעתיק קישורים. **הורדה · *הפרופיל שלכם*** מוסיף לתור את הסרטון, רשימת ההשמעה או הערוץ שאתם צופים בהם; החץ שלידו מחליף פרופילים, והשרביט פותח את ההורדה שלב אחר שלב לבחירת פורמטים, כתוביות ועוד
- **לחיצה ימנית להורדה** — לחצו לחיצה ימנית על כל קישור לסרטון, לרשימת השמעה או לערוץ ב“גילוי” כדי להוריד אותו עם הפרופיל שלכם, לבחור פרופיל אחר מתוך **הורדה באמצעות**, לפתוח את ההורדה שלב אחר שלב או להעתיק את הקישור. אין צורך לפתוח כל סרטון קודם
- **פריסה קומפקטית** — לחיצה אחת בסרגל הכלים של “גילוי” מעבירה אליו את הכרטיסיות של Arroxy ונותנת לדף יותר מקום
- **שורת כתובת** — הקלידו כדי לחפש ב-YouTube, או הזינו כל כתובת אינטרנט כדי לפתוח את האתר
- **הורדות שדורשות חשבון** — התחברו פעם אחת ב“גילוי” ו-Arroxy יוכל להוריד סרטונים שהחשבון שלכם יכול לצפות בהם: הסרטונים הפרטיים שלכם, סרטונים מוגבלי גיל אם גיל החשבון מאומת, ורשימות “לצפייה בהמשך” ו“סרטונים שאהבתם” שלכם. התחברו גם לאתרים אחרים שם, וההורדות מהם ישתמשו בהתחברות הזו כשיצטרכו. Arroxy עדיין מוריד קודם כשהוא מנותק, ומשתמש בהתחברות שלכם ב“גילוי” רק כשהורדה נכשלת באופן שחשבון יכול לתקן
- **שימוש בחשבון משני** — המסך הראשון של “גילוי” מסביר למה: הורדה עם חשבון כרוכה בסיכון מסוים שהחשבון יוגבל. התנתקו מ“גילוי” דרך ההגדרות בכל עת כדי למחוק את ההתחברויות שלכם
- **חוסם פרסומות** — כבוי כברירת מחדל. לחיצה אחת על המגן בסרגל הכלים של “גילוי” חוסמת פרסומות ומעקבים בדפיו, בלי להשפיע על ההורדות. YouTube עשוי להתנגד לחוסמי פרסומות בחשבונות מחוברים

<details>
<summary><strong>🎞️ איכות ופורמטים</strong></summary>

- עד **8K (4320p)**, 4K UHD (2160p), 1440p, 1080p, 720p, 480p, 360p
- **קצב פריימים גבוה ו-HDR** נשמרים כפי שהם — 60 פריימים לשנייה, HDR10
- **שמע** — ייצאו שמע בלבד כ-MP3, M4A/AAC, Opus או WAV. בהורדות אינטראקטיביות אפשר לבחור את רצועות ה-surround/Dolby המקוריות של המקור (AC-3, E-AC-3, 5.1, DRC) כשהן זמינות, או להגדיר ברירת מחדל כללית של **העדפת היקפי / Dolby**
- **פרופילים עם מטרה** — *התמונה הטובה ביותר* (AV1 · VP9) או *טלוויזיה חכמה* (MP4 · H.264), נשמרים כאוטומטי, MP4, MKV או WebM ללא קידוד מחדש. HDR הוא *אוטומטי* (רק כשהמסך שלכם יכול להציג אותו), *SDR* או *HDR*
- **כל קודק בכל רזולוציה** — ההורדה שלב אחר שלב מציגה את AV1, VP9 ו-H.264 זה לצד זה בכל רזולוציה, כך שאפשר לבחור את הקודק שהטלוויזיה או העורך שלכם מנגנים
- **לדעת מה הזרם באמת** — גדלים ש-YouTube שיפר באמצעות AI, שפות שמע שדובבו ב-AI, זרמים בקצב סיביות משופר, סרטוני 360° ועותקים פגומים או עם סימן מים מסומנים. פרופילים מדלגים על זרמים משופרי AI אלא אם התרתם אותם

<summary><strong><a id="macos-first-launch"></a>🍎 הפעלה ראשונה ב-macOS</strong></summary>

גרסאות macOS של Arroxy חתומות ad-hoc אך לא אושרו (notarized) על ידי Apple, ולכן Gatekeeper חוסם את ההפעלה הראשונה עם ההודעה *“Arroxy.app” Not Opened — Apple could not verify “Arroxy.app” is free of malware*. פירוש הדבר ש-macOS אינו יכול לבדוק את היישום מול Apple, לא שיש משהו שגוי בקבצים. התקנה באמצעות Homebrew מדלגת על תיבת הדו-שיח הזו לחלוטין. אם השתמשתם ב-DMG, פקודת Terminal אחת מנקה אותה:

<div align="center">
  <img src="../../build/macOS-warning-Arroxy-is-damaged.png" width="42%" alt="macOS dialog saying Arroxy.app is damaged and cannot be opened" />
</div>

1. גררו את `Arroxy.app` מתוך ה-DMG המחובר אל `/Applications`.
2. פתחו את Terminal והריצו את שתי הפקודות האלה:

```bash
xattr -dr com.apple.quarantine /Applications/Arroxy.app
open /Applications/Arroxy.app
```

הפקודה הראשונה מסירה את מאפיין ההסגר ש-macOS צירף כשהקובץ הורד; השנייה מפעילה את היישום. בדרך כלל אין צורך ב-`sudo`, כי העותק ב-`/Applications` שייך לכם — הוסיפו אותו רק אם קיבלתם שגיאת הרשאות.

**Apple Silicon לעומת Intel:** ב-Mac מסדרת M (M1 / M2 / M3 / M4) הורידו את ה-DMG של `arm64`. ב-Mac עם Intel הורידו את ה-DMG של `x64`. הרצת הגרסה הלא נכונה עדיין עובדת דרך Rosetta, אך איטית יותר באופן ניכר.

> גרסאות macOS נבנות ב-CI על מכונות Apple Silicon ו-Intel. אם נתקלתם בבעיות, אנא [פתחו issue](../../../../issues) — משוב ממשתמשי macOS מעצב באופן פעיל את מחזור הבדיקות ל-macOS.

<details>
<summary><strong><a id="why-warning"></a>⚠️ למה ייתכן שתראו אזהרה</strong></summary>

Arroxy הוא בקוד פתוח וברישיון GPLv3. גרסאות Windows ו-macOS **אינן חתומות בקוד** — תעודות Apple Developer ID ותעודות חתימת קוד EV של Windows עולות כל אחת מאות דולרים בשנה, ופרויקט עצמאי משלם אותן מכיסו. בלי החתימות האלה, Windows SmartScreen ו-Gatekeeper של macOS יזהירו אתכם בהפעלה הראשונה. האזהרות אומרות ש*מערכת ההפעלה שלכם לא מזהה את המפרסם* — הן לא אומרות ש-Arroxy הוא נוזקה.

שלוש דרכים לאמת את Arroxy בעצמכם, בסדר עולה של קפדנות:

- **קראו את קוד המקור.** כל שורה זמינה ב-[GitHub](https://github.com/antonio-orionus/Arroxy) ואפשר [לבנות אותו מקוד המקור](#tech).
- **בדקו את ה-SHA256.** השוו את הקובץ שלכם מול [`SHA256SUMS`](https://github.com/antonio-orionus/Arroxy/releases/latest/download/SHA256SUMS) שפורסם — ראו [אימות ההורדה שלכם](#verify) להלן.
- **הריצו סריקה של צד שלישי.** העלו את הקובץ ל-[VirusTotal](https://www.virustotal.com).

</details>

<details>
<summary><strong><a id="linux-first-launch"></a>🐧 הפעלה ראשונה ב-Linux</strong></summary>

קובצי AppImage רצים ישירות — ללא התקנה. צריך רק לסמן את הקובץ כניתן להרצה.

**מנהל הקבצים:** לחצו לחיצה ימנית על קובץ ה-`.AppImage` ← **מאפיינים** ← **הרשאות** ← סמנו **התר הרצת קובץ כתוכנית**, ואז לחצו עליו לחיצה כפולה.

**Terminal:**

```bash
chmod +x Arroxy-linux-x64.AppImage
./Arroxy-linux-x64.AppImage
```

אם ההפעלה עדיין נכשלת, הריצו אותו בלי חיבור (mount) — אין צורך בחבילת FUSE:

```bash
./Arroxy-linux-x64.AppImage --appimage-extract-and-run
```

**שילוב אופציונלי בשולחן העבודה:** התקינו את [AppImageLauncher](https://github.com/TheAssassin/AppImageLauncher) פעם אחת, וכל AppImage שתלחצו עליו לחיצה כפולה יירשם אוטומטית בתפריט היישומים שלכם — בלי קובץ `.desktop` ידני.

**ארכיון tarball פשוט (ללא FUSE, ללא התקנה):**

גרסת ה-`.tar.gz` היא אותו יישום בלי מעטפת ה-AppImage — חלצו אותה לכל מקום והריצו. אין צורך במתקין או בחבילת FUSE.

```bash
tar xzf Arroxy-linux-x64.tar.gz
./Arroxy-linux-x64/arroxy
```

**הורדות Linux בעמוד הגרסה הן ל-x86_64 בלבד.** במכונות ARM64 (Raspberry Pi, Asahi Linux) ה-Flatpak עדיין מותקן, ואז נכשל בהפעלה עם `bwrap: execvp ldconfig: Exec format error`.

</details>

<details>
<summary><strong><a id="verify"></a>🔐 אימות ההורדה שלכם (SHA256)</strong></summary>

כל גרסה מפרסמת קובץ `SHA256SUMS` לצד הקבצים הבינאריים. כדי לוודא שההורדה שלכם לא נפגמה ולא שונתה בדרך, חשבו את ה-hash של הקובץ מקומית והשוו אותו לשורה ב-`SHA256SUMS`. פתחו את עמוד הגרסה האחרונה ← **Assets** ← הורידו את `SHA256SUMS`.

**Windows (PowerShell או שורת הפקודה):**

```powershell
certutil -hashfile Arroxy-win-x64-Setup.exe SHA256
```

**macOS (Terminal):**

```bash
shasum -a 256 Arroxy-mac-arm64.dmg
```

**Linux (Terminal):**

```bash
sha256sum Arroxy-linux-x64.AppImage
```

</details>

## <a id="why"></a>⚖️ למה Arroxy

השוואה צד לצד עם החלופות הנפוצות ביותר:

|            | Arroxy | Typical free yt-dlp GUI | 4K Video Downloader | JDownloader |     Online converters      | Browser extensions |

| סרטונים שהחשבון שלכם יכול לצפות בהם, בלי לייצא קובצי Cookie |   ✅   |           ⚠️            |         ⚠️          |     ⚠️      |             ❌             |         ⚠️         |
| חינמי, ללא מסלול פרימיום |   ✅   |           ✅            |         ⚠️          |     ✅      |             ⚠️             |         ⚠️         |
| קוד פתוח |   ✅   |           ✅            |         ❌          |     ❌      |             ❌             |         ⚠️         |
| עיבוד מקומי בלבד |   ✅   |           ✅            |         ✅          |     ✅      |             ❌             |         ✅         |

| כתוביות + SponsorBlock |   ✅   |           ⚠️            |         ⚠️          |     ❌      |             ❌             |         ❌         |

⚠️ = חלקית, או רק במסלול בתשלום. ההתחברות בתוך היישום של 4K Video Downloader לסרטונים פרטיים היא תכונה בתשלום; רוב ממשקי ה-yt-dlp החינמיים מקבלים רק קובץ Cookie או קוראים את קובצי ה-Cookie של דפדפן האינטרנט שלכם.

Arroxy נבנה למטרה אחת: קובץ מקומי נקי, בין שהדבקתם כתובת URL ובין שמצאתם את הסרטון ב“גילוי”. ללא הצעות שדרוג, ללא איסוף נתונים.

### <a id="why-explore"></a>🧭 מה שעטיפה פשוטה של yt-dlp לא יכולה: הכרטיסייה “גילוי”

רוב מורידי YouTube החינמיים הם תיבת URL מעל yt-dlp. גם Arroxy משתמש ב-yt-dlp, אבל יש בו גם **גילוי** — דפדפן מובנה ביישום שפותח את YouTube או כל אתר אחר. “גילוי” מוסיף מה שתיבת URL לא יכולה:

- **סרטונים שהחשבון שלכם יכול לצפות בהם, בלי לייצא קובצי Cookie** — הסרטונים הפרטיים שלכם, רשימות “לצפייה בהמשך” ו“סרטונים שאהבתם” שלכם, סרטונים מוגבלי גיל בחשבון שאומת גילו, ודפים באתרים אחרים שדורשים את ההתחברות שלכם. עטיפה פשוטה דורשת ייצוא של cookies.txt או קוראת את קובצי ה-Cookie של דפדפן האינטרנט שלכם. ב-Arroxy מתחברים פעם אחת ב“גילוי” והוא עושה את השאר
- **בלי להעתיק קישורים** — מצאו סרטון, רשימת השמעה או ערוץ ב“גילוי” והורידו אותם בלחיצה אחת, או לחצו לחיצה ימנית על כל קישור בדף
- **חוסם פרסומות כשאתם רוצים** — לחיצה אחת על המגן חוסמת פרסומות ומעקבים בדפים של “גילוי”

## <a id="privacy"></a>🔒 פרטיות

ההורדות מתבצעות ישירות באמצעות [yt-dlp](https://github.com/yt-dlp/yt-dlp) מ-YouTube אל התיקייה שבחרתם — דבר אינו מנותב דרך שרת של צד שלישי. היסטוריית הצפייה, היסטוריית ההורדות, כתובות ה-URL ותוכן הקבצים נשארים במכשיר שלכם.

**ללא מעקב.** Arroxy שולח רק דוחות אנונימיים שעוזרים לנו לספור משתמשים ולתקן בעיות — לעולם לא את הקישורים, הסרטונים, הקבצים או החשבונות שלכם. השליטה בהם נמצאת בהגדרות.

גילוי שומר פרטי כניסה משלו, בנפרד מהדפדפן שלכם, והכניסה מתבצעת תמיד בעמוד של האתר עצמו. הורדה משתמשת בפרטי כניסה רק עבור אותו אתר, קוראת אותם מחדש ומוחקת את העותק שלה לאחר מכן. יציאה מגילוי דרך ההגדרות מוחקת את פרטי הכניסה השמורים.

## <a id="faq"></a>❓ שאלות נפוצות

<details>
<summary><strong>האם זה באמת חינמי?</strong></summary>

כן — ברישיון GPLv3, ללא מסלול פרימיום, וללא נעילת תכונות.

</details>

<details>
<summary><strong>במה Arroxy שונה ממשקי yt-dlp אחרים?</strong></summary>

רוב ממשקי ה-yt-dlp החינמיים הם עטיפות שמקבלות רק קישור. Arroxy מוסיף את **גילוי**, דפדפן מובנה ביישום שפותח את YouTube או כל אתר אחר: גולשים ומורידים בלי להעתיק קישורים, ומתחברים שם פעם אחת כדי להוריד סרטונים שהחשבון שלכם יכול לצפות בהם, כמו הסרטונים הפרטיים שלכם ורשימות “לצפייה בהמשך” ו“סרטונים שאהבתם”, בלי ייצוא קובצי Cookie. ראו [למה Arroxy](#why).

</details>

<details>
<summary><strong>באילו איכויות וידאו אפשר להוריד?</strong></summary>

כל מה ש-YouTube מגיש: 8K (4320p), 4K UHD (2160p), 1440p, 1080p, 720p, 480p, 360p, וכן שמע בלבד. זרמי 60 פריימים לשנייה ו-HDR נשמרים כפי שהם, וההורדה שלב אחר שלב מאפשרת לבחור AV1, VP9 או H.264 בכל רזולוציה.

</details>

<details>
<summary><strong>האם אפשר לחלץ רק את השמע כ-MP3?</strong></summary>

כן. בחרו *שמע בלבד* בתפריט הפורמט ובחרו MP3, M4A/AAC, Opus או WAV.

</details>

<details>
<summary><strong>איך מורידים סרטונים שדורשים חשבון YouTube?</strong></summary>

התחברו פעם אחת בכרטיסיית “גילוי”. Arroxy יוכל אז להוריד סרטונים שהחשבון שלכם יכול לצפות בהם: הסרטונים הפרטיים שלכם, סרטונים מוגבלי גיל אם גיל החשבון מאומת, ורשימות “לצפייה בהמשך” ו“סרטונים שאהבתם” שלכם. הוא משתמש בהתחברות רק כשהורדה נכשלת באופן שחשבון יכול לתקן; כל השאר מורד כמו קודם. זו האפשרות **התחברות ב“גילוי”**, שמופיעה ראשונה ומסומנת כמומלצת בהגדרות ה-Cookie, ו-Arroxy בוחר אותה עבורכם בפעם הראשונה שאתם פותחים את “גילוי”. הוויקי של yt-dlp מציין ש[אוטומציה עם התחברות עלולה לסמן חשבון Google](https://github.com/yt-dlp/yt-dlp/wiki/Extractors#exporting-youtube-cookies), ולכן חשבון משני הוא הבחירה הבטוחה יותר.

</details>

<details>
<summary><strong>האם זה ימשיך לעבוד כש-YouTube משנה משהו?</strong></summary>

yt-dlp מתעדכן אוטומטית בהפעלה, ו-Arroxy מפרסם תיקונים במהירות כש-YouTube משנה משהו. כשהורדה דורשת התחברות, Arroxy משתמש בהתחברות שלכם ב“גילוי” אם התחברתם שם, וקובצי Cookie מקובץ או מהדפדפן שלכם זמינים בהגדרות ה-Cookie.

</details>

<summary><strong>באילו שפות Arroxy זמין?</strong></summary>

50 שפות, מהקופסה: Afaan Oromoo · Bahasa Indonesia · Català · Čeština · Dansk · Deutsch · Eesti · English · Español · Euskara · Français · Galego · Hrvatski · Italiano · Kiswahili · Latviešu · Lietuvių · Magyar · Nederlands · Norsk bokmål · O'zbekcha · Polski · Português · Română · Slovenčina · Slovenščina · Suomi · Svenska · Tiếng Việt · Türkçe · አማርኛ · עברית · العربية · اردو · پښتو · فارسی · বাংলা · हिन्दी · ไทย · မြန်မာဘာသာ · ខ្មែរ · Ελληνικά · Български · Русский · Српски · Українська · 中文 · 日本語 · 한국어 · 繁體中文. ## <a id="troubleshooting"></a>🩺 Troubleshooting

<details>
<summary><strong>🖥️ App won't open / no window appears</strong></summary>

The Arroxy process starts but no window shows up. Most often this is a GPU driver hang during startup. Try, in order:

**1. Check the log.** It records startup, GPU info, and any crash. Path:

| Platform | Path                             |
| -------- | -------------------------------- |
| Windows  | `%APPDATA%\arroxy\logs\main.log` |
| macOS    | `~/Library/Logs/arroxy/main.log` |
| Linux    | `~/.config/arroxy/logs/main.log` |

**2. Launch with hardware acceleration disabled.** Open a terminal / Command Prompt and run the executable with a flag:

```bash
# Windows (Portable) — PowerShell, run from the folder containing the exe
.\Arroxy-win-x64-Portable.exe --disable-gpu

# Windows (Portable) — Command Prompt (cmd.exe), from the same folder
Arroxy-win-x64-Portable.exe --disable-gpu

# Windows (Installed) — works in both PowerShell and cmd.exe
"%LOCALAPPDATA%\Programs\Arroxy\Arroxy.exe" --disable-gpu

# macOS
/Applications/Arroxy.app/Contents/MacOS/Arroxy --disable-gpu

# Linux (AppImage)
./Arroxy-linux-x64.AppImage --disable-gpu
```

If that works, the GPU/driver is the cause. Make the change permanent (next step).

**3. Persist the flag via `argv.json`.** Create the file at:

| Platform | Path                                             |
| -------- | ------------------------------------------------ |
| Windows  | `%APPDATA%\arroxy\argv.json`                     |
| macOS    | `~/Library/Application Support/arroxy/argv.json` |
| Linux    | `~/.config/arroxy/argv.json`                     |

On Flatpak, both `main.log` and `argv.json` live under
`~/.var/app/io.github.antonio_orionus.Arroxy/config/arroxy/`
(for example `logs/main.log`).

With contents:

```json
{ "disable-hardware-acceleration": true }
```

Arroxy reads this before opening any window, so it works even when the window never appeared.

**4. Other flags worth trying** (combine if needed): `--disable-software-rasterizer`, `--disable-gpu-sandbox`, `--in-process-gpu`.

**5. Stale window position.** If the window may be opening off-screen (multi-monitor change since last run), delete `<userData>\window-state.json` and relaunch.

**6. Still stuck?** Open an issue with your OS version and any output from running with `--enable-logging --v=1`. If the app window does open, attach the file from **Settings → Save diagnostics file**: it holds both logs and your app details, with your user folder name removed. Otherwise attach `main.log`.

</details>
