1. FFmpeg + FFprobe (https://ffmpeg.org/)
-----------------------------------------------------------------------
License: GNU General Public License version 3 (GPLv3)

FFmpeg is not included in Arroxy's installer. On first launch Arroxy
downloads an approved FFmpeg package for your platform from
https://github.com/antonio-orionus/arroxy-runtime-binaries/releases
and keeps it across Arroxy updates.

These FFmpeg builds are configured with `--enable-gpl` and include
GPL-licensed components (libx264, libx265, etc.). Each package contains
its own NOTICE.txt, and the release it is published in lists the exact
upstream build and where its corresponding source code is available.

Upstream builds:
  - Windows + Linux: https://github.com/BtbN/FFmpeg-Builds (gpl-shared variants)
  - macOS:           https://ffmpeg.martin-riedl.de/

Full GPLv3 license text: https://www.gnu.org/licenses/gpl-3.0.txt
